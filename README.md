AI or Real Photo?

A photo guessing quiz where you identify whether an image was created by AI or is a real photograph.

Project Introduction

This program lets users look at an image and choose whether it is an AI-generated image or a real photo.

Users can select a difficulty level, answer 10 questions, and check their final score at the end.

Features

1. Difficulty Selection

There are three difficulty levels:

Level 1 (Easy)

Level 2 (Normal)

Level 3 (Hard)

Each difficulty level contains 10 photo questions.

2. AI Photo / Real Photo Choice

After viewing an image, users can choose between:

🤖 AI Photo

📸 Real Photo

The program immediately shows whether the answer is correct or incorrect.

3. Score Tracking

The score increases by 1 point for each correct answer.

After completing all 10 questions, the program displays the final score.

How to Use

Open the program.

Select a difficulty level.

Look at the displayed image.

Choose AI Photo or Real Photo.

Complete all 10 questions.

Check your final score.

Choose to retry the quiz or return to the main menu.

Technologies Used

HTML

CSS

JavaScript

HTML is used to create the structure of the webpage, CSS is used for the design and layout, and JavaScript is used for the quiz functions, answer checking, difficulty selection, and score calculation.

Purpose

As AI technology continues to develop, AI-generated images are becoming increasingly similar to real photographs.

This project was created to let users compare and identify AI-generated images and real photographs through a simple quiz.
